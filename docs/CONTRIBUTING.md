# 贡献指南

欢迎通过 Issue 描述需求、通过 PR 提交改进。请保持项目定位：企业微信与 Slack 之间的受限文本与可选授权群截图传输层。新增模型调用、账号自动化、权限扩展或后台采集不属于当前传输层范围。

提交前：

1. 使用 Node.js 24，在干净目录运行 `npm ci --ignore-scripts`、`npm run check`。
2. 为变更补充测试，尤其是群/本人准入、严格前置路由标记（含传输层移除换行后的同行正文及空正文拒绝）、评审轮次与过期 ID、隐私隔离、身份固定、跨线程串话、防循环、旧状态隔离迁移和重试边界。
3. 更新环境变量说明和运行限制；明确测试用例使用模拟服务还是真实账户。
4. 检查暂存区，排除 `.env`、令牌、运行状态、日志、聊天样本、私有源码和机器相关配置。
5. 不把单元测试通过写成真实端到端验证通过；现场能力按环境独立验收，不承诺任意响应方免费、即时可用。
6. 不在测试、安装或服务启动阶段自动创建远端账户、修改权限或接管其他机器人。

PR 应说明变更目的、数据流变化、测试命令及结果，以及尚未验证的真实服务场景。示例请使用虚构 ID 和文本。

贡献将按仓库 MIT License 发布。只提交你有权公开的内容；不要复制未获许可的私有代码。

文档入口见 [README](../README.md)；协议变化只在对应主要文档维护，安装与回退统一放在 [部署维护](../deploy/README.md)，公共文档不保存私人部署流水。依赖版本由锁文件固定，变更前审阅官方来源与生产审计结果。CI 只读仓库并运行本地测试，不连接机器人或自动部署。
